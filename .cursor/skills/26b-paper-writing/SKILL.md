# 26B 论文书写（按问题分章）

其他 agent 写或改这篇论文时**必须先读本文件**，再只加载当前子问题的指引：

- 问题一 → [q1.md](q1.md)
- 问题二 → [q2.md](q2.md)
- 问题三 → [q3.md](q3.md)
- 问题四 → [q4.md](q4.md)

未点名写哪一问时，先改布局与复用链，再逐问打开对应文件。不要凭训练数据编造成绩或航路。

## 用户指定的章节布局（不得改结构）

每个问题作为**大标题独立介绍**。每个问题下面固定四个二级标题，顺序不可换、不可合并、不可把四问揉进同一「模型建立与求解」章：

```markdown
# 问题一  <模型名>
## 模型建立
## 模型求解
## 结果分析
## 模型验证

# 问题二  <模型名>
## 模型建立
## 模型求解
## 结果分析
## 模型验证

# 问题三  ...
# 问题四  ...
```

问题分析、假设、符号表放在四问之前的总论里；灵敏度若与单问验证重复，单问「模型验证」写本问风险，总论只做跨问对照。本 skill 只管四问正文。

## 工作流程

1. 确认当前默认策略：读 `src/runner_q3.py`、`src/runner_q4.py` 的 docstring 与默认 `*_path_profile`。主文只写**将要提交的默认入口**。
2. 活数据：成绩读 `output/baselines.md` 与其指向的 JSON；覆盖几何读 `src/coverage.py`；定位核读 `src/geometry.py`、`src/candidate.py`；图注口径读 `output/figures/QA_figures.md`。
3. 打开对应 `qN.md`，按其「建立 / 求解 / 结果 / 验证」清单写或改。
4. 数字必须能回指文件；没有文件就写「待补」并列出路径，禁止编造。
5. 改完跑本节自检清单。符号、判定、航路与上游章节冲突时，改后文去对齐已锁定的问题一公式，而不是另写一套。

## 全文模型族（四问必须同一套）

有界误差测向（AOA）集合估计，不是高斯点估计。

| 问 | 模型名（标题用这个） | 角色 |
|----|----------------------|------|
| 一 | 有界角扇半平面交的集合估计模型 | 定义可行域 \(R\)、直径、最小包围圆、能否 20 m 清除 |
| 二 | 最坏交会几何下的正交第二站选址模型 | 定义候选带与下一测站 |
| 三 | 最坏接收半径等圆覆盖与序贯交会清除模型 | 全向听全 + 调用一二问接口清除 |
| 四 | 定向前瓣可见覆盖与序贯交会清除模型 | 把「可听」改成前瓣半平面，定位核不变 |

复用链（后续问题必须显式引用问题一、二的公式编号）：

```text
测站 + 示向
  → 问题一 locate：R、diam、SEC、(c_SEC, r_SEC)、can_clear_20
  → 不能清则问题二 next_stations（定向再加前瓣兼容）
  → 问题三/四只决定何时去听、何时去清，不得另写沿示向爬行作为常规定位
```

## 锁定口径（写错即视为与代码不一致）

- 示向误差：题面 \(\pm 1^\circ\) 闭区间。实现余量：问题三 \(\delta=1.01^\circ\)（两位小数），问题四默认 \(\delta=1.0^\circ\)。正文写清二者，不要混成同一个数却不解释。
- 清除：\(r_{\mathrm{SEC}}\le 20\,\mathrm{m}\) 才 `/clear` 圆心。**禁止**用直径 \(\le 40\,\mathrm{m}\) 代替。
- 近共线：\(|\sin\beta|<0.08\) 强制再测。
- `no_signal` 只收缩可行集，不把频道标成全局不存在。
- 主方法不是 LS / ML / CRLB / 卡尔曼。那些最多当对照，并写明与 \(\pm 1^\circ\) 闭区间不符。
- 爬行（creep）只是有界兜底，不是问题三/四的主路径。
- 实验分支（`run_q3_defer` 的 \(8\times 1200\)、`run_q4_nofar` 的 \(12\times 2100\)、`pathopt` 交错、未采纳的 Step 8 插入）只能写「对照 / 未采用」，不能写进该问「模型求解」主流程。

默认入口（若代码已改，以 runner 为准，并在正文改航路描述）：

- 问题三：`run_q3()` → `q3_path_profile="batch"`，原点 + 正六边形 \(6\times 1150\,\mathrm{m}\)（相位 \(10^\circ\)），先搜后清，再滚动时域开放路批量清除。
- 问题四：`run_q4()` → `q4_path_profile="hexbatch"`，原点 + 内正七边形（半径 \(=\rho_{\min}\)，约 \(997\,\mathrm{m}\)，用 `coverage.q4_opt_inner_r()` 核实）+ 外正十二边形 \(12\times 1865\,\mathrm{m}\)，先搜后清，再 RH 清除。无额外 900 m 途听环。

## 四段写法（每问都遵守）

| 二级标题 | 写什么 | 不写什么 |
|----------|--------|----------|
| 模型建立 | 问题类型、数学对象、判定或目标、与上游公式的关系 | Python 函数名、调参过程、成绩 |
| 模型求解 | 信息结构 → 选定算法 → 编号步骤 → 复杂度/完备性口径 | 「用 Python 实现了」；把未采用分支写成主算法 |
| 结果分析 | 可追溯数值 + 回到题意的一句解释 + 指定图/表 | 无单位数字；把验证段的包含率重复当「成绩」 |
| 模型验证 | 与该问风险匹配的检验（几何算例 / 覆盖证书 / mock 全清 / 演练一致性） | 把 mock 坐标误差写成官方定位精度；无真值演练报 RMSE |

图表：先写「为何看它」，再写「它证明哪条判定」。图源优先 `output/figures/` 与 `output/figures/QA_figures.md`。

## 文风与合规

- 中文正文。中英之间空一格。关键公式编号，后文用编号引用。
- 禁止套话：完美、充分体现、深入探讨、重要参考、广泛前景。
- 不暴露队名、校名、学号。不写正式测试（正式入口保持关闭）。
- 成绩只报演练或 mock，并标明场景。一律附 秒/源（局内 \(T_v/\text{cleared}\)）。
- 创新只写相对基线真正改过且有对照的机制。

## 改稿时的最小编辑

用户说「按 skill 调整问题 k」时：只动该章四个二级标题内部；若必须改符号或判定，同步问题一建立段与后问引用句，并在回复里列出改动的公式编号。
