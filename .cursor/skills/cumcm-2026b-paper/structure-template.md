# 高教社杯数模论文 — 可填充结构模板

**排版（强制）**：以 [format-rules.md](format-rules.md) 为准。本模板默认 **符号说明在模型假设之前**（本队/2025B 合并稿）。

将下方模板复制为工作稿。方括号为占位。

```markdown
# [方法导向标题：基于××的××模型/优化设计]

## 摘要

[1–2 句总起：研究对象 + 总体方法视角 + 本文交付物。]

针对问题一，[思路]。[关键步骤一句]。最终[指标]=[数值]。

针对问题二，[在问题一基础上如何扩展]。[方法]得[关键结果]。

针对问题三，[相对问题二的变化]。[方法]得[关键结果]。

关键词：[方法1]；[方法2]；[方法3]；[对象或指标]

## 一、问题重述

### 1.1 问题背景
[背景落到研究对象。关键物性/方法加文献上标。]

### 1.2 问题要求
**问题一：** … → …
**问题二：** … → …
**问题三：** … → …

## 二、问题分析

### 2.1 问题一分析
### 2.2 问题二分析
### 2.3 问题三分析

## 三、符号说明

[1–2 句。三线表：符号 | 含义 | 单位/备注。]

## 四、模型假设

1. …
2. …
（3–8 条）

## 五、问题一：[副标题]

### 5.1 数据预处理
### 5.2 模型建立
### 5.3 模型求解
### 5.4 求解结果
### 5.5 模型验证
### 5.6 结论

## 六、问题二：[副标题]
（6.1–6.6 同六段式）

## 七、问题三：[副标题]
（7.1–7.6 同六段式）

## 八、模型评价与推广

### 8.1 模型优点
### 8.2 模型不足与改进
### 8.3 模型推广

## 参考文献
（约 15–20 条；正文上标集合 = 文末编号集合；条目小五）

## 附录
### 附录 A 主要程序文件
### 附录 B 核心代码 / 结果文件说明
### 附录 C 运行环境与复现
```

独立单问稿可将问题章改为「四、问题一」起步；**整篇合并稿**用五→七编号。
