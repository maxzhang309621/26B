> 入口见同目录 [SKILL.md](SKILL.md)。

# 数模 Word 排版与文风规范

生成或改写 Word 文档（`.docx`）时**必须**遵循以下规定。

---

## 本队叙述文风（必须）

对标来源：（1）历年高教社杯优秀论文的递进与硬数字习惯；（2）本队学术论文写法（挑战—方案—机理—硬结果）。  
排版服从本 skill；**句子节奏服从本节**，不要写成清单口吻的“判据：…本检验通过”。

### 推荐推进句式

- **问题/难点先行**：其一…其二… / 然而… / 难点在于…
- **方案收束**：为解决上述问题… / 其核心在于… / 针对上述局限…
- **步骤衔接**：首先…随后…最后…
- **公式后解释**：式中… / 其中…（说明符号物理含义，用 `add_eq_followup`）
- **结果嵌入叙述**：先写要回答的问题与读法，再嵌入带单位的数字，忌连续堆数

### 语气禁止

- 禁止空喊「巧妙」「完美」「较为可靠」而无证据。
- 禁止机械标签成文：不要用「判据：」「读图：」「本检验通过：」作为段落开头或小标题式口号；  
  **逻辑上仍要有**标准→证据→解释→收束，但写成连贯学术段落。
- 禁止把优化器吐出的不可辨识参数写成“测得值”（见下文 \(N\) 规则）。

### 优秀论文习惯（保留）

- 摘要/结论仍要有**可核对硬数字**；正文分析段以文字为主、数字为锚。
- 后问明确衔接前问（“在问题一导出的…基础上”）。
- 验证链条完整：自洽 → 交叉一致 → 敏感性 → 误差边界 → 模型取舍。

## 字体与字号

| 元素 | 中文字体 | 英文字体 | 字号 |
|------|----------|----------|------|
| 正文 | 宋体 | Times New Roman | 五号（10.5pt） |
| 一级标题（如「三、」「四、」） | 黑体 | Times New Roman | 小三（15pt），居中 |
| 二级标题（如「4.1」） | 黑体 | Times New Roman | 小四（12pt），左对齐 |
| 三级标题（如「4.1.1」） | 黑体 | Times New Roman | 五号（10.5pt），左对齐 |
| 表题 | 宋体 | Times New Roman | 小五（9pt），**加粗**，居中 |
| 图题 | 宋体 | Times New Roman | 小五（9pt），居中 |
| 表格正文 | 宋体 | Times New Roman | 五号（10.5pt），居中 |
| **正文文献上标** `[n]` | 宋体 | Times New Roman | **五号（10.5pt）** + Word 上标 |
| **参考文献条目** | 宋体 | Times New Roman | **小五（9pt）**，无首行缩进 |

正文段落：两端对齐，**单倍行距**，首行缩进 2 字符（约 0.74cm）。

标题（一级/二级/三级）：段后留白约 **5 磅**，与正文之间留出小间距；段前保持默认或最小。

## 公式

- **公式后面不要加序号**（不写 `(1-1)`、`(6-3)` 等）。
- 公式单独居中一行。
- 若公式后紧跟的是**解释该公式**的文字，**不要另起一段**：使用 `add_eq_followup()`，无首行缩进，段前间距为 0，紧接公式。

## 表格（三线表）

- 采用**三线表**：仅三条横线——表格顶线、表头与首行数据之间的分隔线、表格底线。
- **无竖线**，数据行之间无横线。
- **表题放在表格上方**：居中，宋体，**加粗**，小五。
- 使用 `add_table()`，勿手写 Grid 全框线。

## 图片

- 图片居中。
- **图题放在图片下方**：居中，宋体，小五（不加粗）。
- 若图后紧跟解释文字，用 `add_eq_followup()`，不另起缩进段。
- **图片应分散插入在对应内容处**，不要集中堆在同一小节末尾或附录。
- 优先使用 `add_figure(doc, path, caption)` 直接嵌入绝对路径图片；路径不确定时用 `try_add_figure()`。
- **每张图仅含一个子图**：禁止将多面板拼图写入 Word；程序输出应为 `{prefix}_preprocess.png` 等单张文件。
- **PNG 内不写图题**：禁止 `title` / `suptitle`；图题仅在 Word 中通过 `add_figure()` 置于图下方。

### 分析过程中插图（鼓励）

六段式结构的**每一节**在叙述需要时都可以插图，使推导—计算—结果—验证链条更完整，不必等到「求解结果」或「模型验证」才放图。

| 小节 | 常见插图类型 | 示例 |
|------|--------------|------|
| X.1 数据预处理 | 原始/清洗后光谱、窗宽选取、去基线残差 | 附件全谱、SG 滤波对比 |
| X.2 模型建立 | 物理示意图、色散曲线、坐标系/光路 | 双光束光路、n(ν̃) 曲线 |
| X.3 模型求解 | 流程图、FFT 谱、峰谷标注、拟合面板 | 六区域证据图、频域主峰 |
| X.4 求解结果 | 结果对照图、汇总柱状/误差棒 | 双角度厚度对比 |
| X.5 模型验证 | 一致性、敏感性、残差/诊断图 | 窗宽对照、谐波比证据 |
| X.6 结论 | 一般不再新增图 | — |

写作要求：

- **图前一句引导**（`add_para`）：说明下图展示什么、与当前步骤的关系。
- **图后读图分析**（`add_eq_followup`）：指出关键特征、数值或与公式/表的对应，避免「只有图没有解释」。
- **全文图号连续**（图 1、图 2、图 3… 直至文末），按正文出现顺序编号；**禁止**每问从「图 1」重新起算。
- 正文「见图 n / 图 n」须与图题编号一致；改图号时同步改正文交叉引用。
- 有 `output/` 或脚本已生成的 png 时**优先嵌入**；暂缺文件时仍写引导句并留 `try_add_figure` 占位。

## 全文一级结构（整篇 B题.docx，必须）

生成或重组完整论文时，按下列顺序（对标优秀论文；**符号说明在模型假设之前**）：

```text
标题
摘要 + 关键词
一、 问题重述
二、 问题分析
三、 符号说明              ← 三线表：符号 | 含义 | 单位/备注；在假设与问题一之前
四、 模型假设
五、 问题一：双光束斜入射干涉厚度模型
六、 问题二：碳化硅外延层厚度反演与可靠性分析
七、 问题三：多光束可观测判定与硅片厚度测定
八、 模型评价与推广        ← 优点 / 不足与改进 / 推广
参考文献                  ← 问题重述、问题分析须有上标引用；著录体例同本队学术论文（GB/T 7714 期刊式）
附录                      ← 页表格式对标优秀论文附录（见下）
```

### 章节命名（问题章必须带副标题）

| 一级标题 | 说明 |
|----------|------|
| 五、 问题一：双光束斜入射干涉厚度模型 | 原「四、问题一」，子节编号 **5.x** |
| 六、 问题二：碳化硅外延层厚度反演与可靠性分析 | 原「五、问题二」，子节 **6.x** |
| 七、 问题三：多光束可观测判定与硅片厚度测定 | 原「六、问题三」，子节 **7.x** |

独立单问文档仍可用「四/五/六、问题×」起步；**整篇合并稿**必须用上表五→七编号。

### 三、符号说明

- 一级标题居中黑体小三：「三、 符号说明」。
- 开篇 1–2 句说明用途（使推导符号统一）。
- **必须用三线表**，列：符号 | 含义 | 单位/备注。
- 表题：「表 1  主要符号说明」（若前文已有表，按全文表号顺延）。
- 公式中新出现的重要符号应及时与表一致。

### 八、模型评价与推广（本队文风）

写成连贯学术段，勿空喊；建议三级结构：

```text
8.1  模型优点
8.2  模型不足与改进
8.3  模型推广
```

- **优点**：对应实际做过的点（物理可解释、双角度一致性、四项多光束门控、色散多段稳定性、误差分层等），每条有事实锚点。
- **不足**：常数 n / 绝对标定 / \(N\) 不可辨识 / 未给晶型温度等，写清边界。
- **推广**：可迁移到其他外延材料红外测厚、在线质检、更换色散先验后的流程复用等。

### 参考文献与正文引用（必须一一对应）

#### 字号与版式

| 对象 | 字号 | 说明 |
|------|------|------|
| 正文中的文献上标 `[n]` | **五号（10.5pt）** + 上标 | 与正文字号相同，**不要用小五做上标** |
| 「参考文献」标题下的著录条目 | **小五（9pt）** | 宋体/TNR；无首行缩进；两端对齐或左对齐均可 |
| 「参考文献」一级标题本身 | 同其他一级标题 | 小三黑体居中 |

#### 对应关系（硬约束）

1. **正文上标 ⊆ 文后文献表**：凡正文出现上标 `[n]`，参考文献中必须有且仅有一条以 `[n]` 开头的著录；禁止悬空引用。
2. **文后文献宜均被引用**：列入参考文献的条目应在正文（重述/分析/建模/方法/验证等）至少出现一次上标；不要堆“只挂表、正文从不引”的文献。本队 2025B 论文参考文献目标约 **15–20 条**（默认补足至 **18 条**），覆盖材料、干涉测厚、色散/椭偏、信号处理、稳健回归、多光束光学、信息准则、重采样等。
3. **编号连续**：从 `[1]` 起连续编号到 `[N]`，不跳号；增删文献后须同步改正文上标。
4. **交付前自检**：脚本或人工核对 `body_cite_nums == ref_nums`（集合相等）。不相等不得交稿。

#### 何处必须引用

- **问题重述、问题分析**：材料物性、干涉测厚方法、标准/工程背景等关键陈述须上标。
- **模型建立**：色散模型、Drude/晶格振子、Airy/多层膜、经典光学公式来源须上标。
- **预处理/数值方法**：Savitzky–Golay、Theil–Sen、Bootstrap、AICc 等算法出处须上标。
- 同一句多篇可用连续上标如 `[4][5]`，或写作 `[4,5]` / `[4-6]`（若用后者，须保证区间内每条都在文献表中）。

#### 著录体例

- 参考文献置于「八、模型评价与推广」之后、附录之前。
- 格式对齐本队学术论文（GB/T 7714 期刊式）：  
  `[n] Author. Title[J]. Journal, year, vol(issue): pages.`；专著/标准用 [M] / [S]。
- 文献域应覆盖：SiC 应用与测厚背景、红外干涉/椭圆偏振色散（如 Tiwald、Edwards–Ochoa）、多层光学（Born/Yeh）、信号处理与稳健回归、模型选择（AICc）、不确定度（Bootstrap）等（按正文实际引用取舍，但须满足“上标↔条目”相等）。

#### 生成/修补脚本约定

- 写上标时用 `set_run_font(..., BODY_SIZE)`（五号）再 `run.font.superscript = True`。
- 写参考文献条目时用 `CAPTION_SIZE` / `Pt(9)`（小五），**不要**用正文五号。
- 增补文献后：先扩表到目标条数 → 再在对应方法段补上标 → 最后跑集合相等校验。

### 附录（页表格式）

对标优秀论文附录页表习惯（用户指定样例：`…/C132.pdf` 附录页表风格）：

- 一级标题：「附录」（居中）或「附录 A / 附录 B …」。
- 以**三线表**为主呈现清单类信息，表题在上、小五加粗居中。
- 建议至少包含：
  - **附录 A** 主要程序文件说明（文件名 | 功能 | 备注）
  - **附录 B** 主要输出结果文件（文件名 | 内容说明）
  - **附录 C** 运行环境与复现命令（可短表或条目）
- 长代码可不整篇粘贴；以文件清单 + 关键入口（`src/main.py`）为主，与优秀论文“附录可核查”一致。

## X.4 求解结果 / 求解分析（文字要够厚）

一眼望去若**数字占比过大**，视为不合格，必须加厚分析文字。

### 写法

1. **先设问再给数**：本步要回答什么（一致性？级次是否跳变？与前问预期是否同向？）。
2. **数字嵌在因果句中**：每个关键数后面跟半句物理/方法含义；不要写成「A=…，B=…，C=…」的报数清单。
3. **多通道对照要讲结构**：同量级、有无离群、15° 是否略薄（斜入射方向）等；表/图后至少一段读图。
4. **篇幅感**：单附件求解分析通常不少于 4–6 句连贯论述；汇总结果段把「一致性 → 融合 → 通道对照」分步写清。

### 反例 → 正例

- 反例：「采用值 7.883 μm，峰 7.839 μm，谷 7.926 μm，FFT 7.724 μm，相对差 1.16%。」
- 正例：先说明峰谷接近意味着极值类型不敏感，再给出厚度；再说明 FFT 略低但仍同量级、未见级次跳变；最后才点出相对差并接到图。

## X.5 模型验证（必须写详细）

「模型验证」是评审重点：证明结果**可解释、可复核、边界清楚**。  
禁止只写「结果合理」「一致性较好」等空话；必须**有检验标准、有数字锚点、有图（能配则配）、有逻辑闭环**，且**分析文字篇幅明显大于纯数字罗列**。

### 写作目标

回答三件事（缺一不可）：

1. **对不对**：公式/算法在极限情形或交叉通道下是否自洽；
2. **稳不稳**：换角度、换窗宽、换通道后主结论是否漂移过大；
3. **边界在哪**：哪些误差能消除、哪些是系统误差、哪些参数不可辨识。

### 推荐三级小节结构（按问裁剪，一般 3–5 个）

```text
X.5.1  内部一致性 / 退化自洽检验     ← 先证模型没推错
X.5.2  交叉验证（双角度 / 双通道等） ← 再证数据与斜入射修正自洽
X.5.3  敏感性与稳健性               ← 窗宽、采样、初值等
X.5.4  误差分解（统计 vs 系统）     ← Bootstrap 与折射率/掺杂等
X.5.5  模型取舍与适用范围           ← 双光束 vs 多光束、色散可用性等
```

逻辑顺序固定为：**自洽 → 交叉一致 → 敏感性 → 误差边界 → 模型取舍**。  
不要先写结论再补证据，也不要把误差讨论拆散到求解节里只留一句。

### 每小节的最小写作模板（必须；写成连贯段落）

每个 `X.5.k` 小节在**逻辑上**含下面四步，缺图时可弱化图，但第 1、3、4 步的文字不能省。  
**表述上写成学术连贯段**，不要用「判据：」「读图：」「本检验通过」作标签。

1. **标准**（融入段首）：用什么门槛算可接受  
   - 例：说明双角度相对差通常应小于 1%–2%，再进入证据。
2. **证据呈现**：表和/或单张图  
   - 图前一句引导（看什么）；图后读图（特征 + 数字 + 含义）。
3. **分析**：把特征翻译成对模型的支持或限制；可读「位置—离散—趋势」或「是否形成完整证据链」。  
   - 例：两角度落在联合水平线附近 → 斜入射修正与级次识别同时成立。
4. **收束**：用叙述句说明该检验对主结论的影响（成立 / 部分成立 / 不成立及如何处理），避免口号式「本检验通过」。

### 读图规范（验证节尤其严格）

- **一图一检验点**：验证用图尽量单指标（一致性、残差、谐波矩阵、色散 \(n(\tilde\nu)\) 等）。
- **数字入文但不堆砌**：图上关键厚度、相对差必须在正文出现，但要嵌在读图句中。
- **因果链**：图 → 特征 → 对应哪条物理假设/哪条公式 → 是否支持主结果。
- 推荐验证图来源（`output/`，单张单图）：

| 检验目的 | 优先用图（示例文件名） |
|----------|------------------------|
| 双角度一致性 | `angle_consistency_sic.png` / `_si.png` |
| 多通道厚度对照 | `thickness_comparison_sic.png` |
| 多光束是否成立 | `multibeam_evidence_sic.png`、`{key}_fft.png`、`{key}_multibeam_diag.png` |
| 拟合质量 | `{key}_stripes.png`、`{key}_residual.png`、`model_quality_*.png` |
| 色散/系统误差 | `dispersion_*_n.png`、情景厚度类图 |
| 理论光路（问题一） | 双光束干涉示意图 |

### 色散厚度与载流子浓度 \(N\)（报告规则）

| 对象 | 能否写入主结论 | 正确写法 |
|------|----------------|----------|
| 双光束/多光束主厚度 | 能 | 主表报告值（如 SiC ≈7.85 μm） |
| 色散门控/对照厚度 | 能（对照） | 与主结果**对照**（如 ≈7.84 μm），**不得相加** |
| 固定掺杂情景厚度带 | 能（系统区间） | 如 7.15–8.33 μm，标明情景假设 |
| 优化器候选 \(N_\mathrm{epi},N_\mathrm{sub}\) | **主表不能当测得值** | `concentration_identifiable=false` 或 `reported_*=null` 时：只可在附录/正文说明为「条件拟合候选、门控未通过」；主结论不报唯一浓度 |
| 固定情景里的 \(N\) | 不是反演结果 | 文献/工程假定输入，用于扫系统误差 |

要点：**有候选数 ≠ 测准了**。厚度靠条纹周期相对稳健；\(N\) 依赖绝对反射率标定，标定不足或触边、改善不足时必须丢弃点估计。

### 禁止事项（模型验证专条）

- 不要用「较为可靠」「具有一定说服力」代替具体标准与数字锚点。
- 不要把求解结果表整表复制进验证节而不做新的检验。

### 分问题内容清单（2025B）

**问题一（理论验证为主）**

- 正入射退化：\(\theta_0\to 0\) 回到 \(d\approx 1/(2n\Delta\tilde\nu)\)；用叙述说明极限自洽意义。
- 斜入射一致性：同一 \(\Delta\tilde\nu\) 下 \(\theta_0\) 增大则表观 \(d\) 减小；为问题二双角度交叉验证奠基。
- 折射率灵敏度：\(\Delta d/d\approx -\Delta n/n\)；划定适用域（透明弱色散窗、双光束近似）。
- 可配图：光路示意、色散 \(n(\tilde\nu)\)（说明为何透明窗可取常数 \(n\)）。

**问题二（数值验证为主，须详细）**

- 峰/谷双通道、FFT 与极值同量级；双角度相对差（约 1.16%）与加权联合厚度——**先分析后给数**。
- **必配读图**：双角度一致性图、厚度通道对比图（位置—离散—趋势）。
- 窗宽/采样敏感性：对照候选窗，主结论漂移量级及为何仍稳健。
- 统计误差（Bootstrap）与系统误差（\(n\)、掺杂情景）；色散对照可用，\(N\) 不可唯一反演时按上表规则写。
- 与多光束关系：谐波比等证据不足 → 维持双光束；**必配**多光束诊断图并读「证据链是否完整」。

**问题三（模型判别验证为主）**

- 四项标准（谐波比、有效反射率、RMSE 改善、\(\Delta\)AICc）是否**全部**满足。
- Si 满足 → Airy；SiC 不满足 → 不强制升级；用证据矩阵/频谱图逐项读图。
- 说明「残差下降」 alone 不足以判多光束（防过拟合）。

### 验证 → 结论的衔接

- `X.5` 末尾用 2–4 句总括：哪些检验支持主结论、采用值、主要剩余不确定度（叙述体）。
- `X.6` 只保留：任务完成了什么、最终报告的 \(d\)（及模型名）、适用范围一句话；**不再展开**图表与检验过程。
