# 交稿前质检清单

权威细则：[format-rules.md](format-rules.md) · 入口：[SKILL.md](SKILL.md)

## A. 结构完整性

- [ ] 标题含方法或对象，非空泛「研究」
- [ ] 摘要含总起 + 分问 + 关键词
- [ ] 问题重述与题面各问交付物对齐
- [ ] 问题分析覆盖每一问且说明问间递进
- [ ] **符号说明在模型假设之前**（整篇合并稿）
- [ ] 假设 3–8 条且可操作
- [ ] 符号表与正文一致
- [ ] 每问六段式含：建立 → 求解 → 结果 → **验证** → 结论
- [ ] 评价含优点与缺点改进
- [ ] 参考文献真实可查；附录可核查

## B. 摘要竞争力

- [ ] 「针对问题一/二/三」结构清晰
- [ ] 方法名可检索；关键数值与正文一致
- [ ] 无抄题、无空话段

## C. 引用与图表

- [ ] 正文上标集合 = 文末文献编号集合（约 15–20 条，2025B 常 18）
- [ ] 上标五号、参考文献条目小五
- [ ] **全文图号连续**；正文「见图 n」与图题一致
- [ ] 图题在下、表题在上；三线表
- [ ] 不可辨识的 \(N\) 未写入主结论

## D. 排版格式

- [ ] 一级标题：黑体小三、居中
- [ ] 二级/三级：黑体小四/五号
- [ ] 正文宋体五号；英文 Times New Roman 五号
- [ ] 段落两端对齐、首行空两格；单倍行距
- [ ] 公式居中、无式编号；公式/图后解释不另起缩进段

## E. 竞赛合规（用户自行核对当届通知）

- [ ] 页数、匿名、承诺书等
- [ ] 指定表格/result 文件名

## 审校优先级

1. 摘要与结果一致  
2. 题面强制输出齐全  
3. 模型逻辑闭环 + 验证够厚  
4. 引用集合相等 + 图号连续 + 版式细节
