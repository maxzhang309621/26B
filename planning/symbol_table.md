# 问题 3 符号表

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| G | 干扰源真实位置 | m，比赛圆域半径不超过 1800 |
| S_i | 第 i 个检测位置 | m |
| theta_i | 在 S_i 返回的示向度 | degree |
| delta | 单次示向角保守半宽 | degree；第 1 步沿用 1，第 2 步评估舍入余量 |
| F | 多次观测形成的位置可行域 | 二维集合 |
| c_SEC | 可行域最小包围圆圆心 | m |
| r_SEC | 可行域最小包围圆半径 | m |
| R_clear | 成功清除距离阈值 | 20 m |
| R_near | 返回 near 的距离阈值 | 5 m |
| R_eff | 单源有效接收半径 | 1000–1500 m |
| T_v | 虚拟总时间 | s |
| T_r | 真实运行时间 | s，最多 1200 |
