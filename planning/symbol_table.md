# 问题 3 符号表

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| G | 干扰源真实位置 | m，比赛圆域半径不超过 1800 |
| S_i | 第 i 个检测位置 | m |
| theta_i | 在 S_i 返回的示向度 | degree |
| delta | 单次示向角保守半宽 | degree；问题 3 取 1.01，覆盖 ±1 与两位小数舍入 |
| F | 多次观测形成的真实位置可行域 | 二维集合，含角锥、场地圆域、正检测距离上界与无信号排除圆 |
| F_out | 用于安全清除证明的保守凸外包络 | 二维凸多边形；忽略非凸无信号排除圆，不小于 F |
| c_SEC | 可行域最小包围圆圆心 | m |
| r_SEC | 可行域最小包围圆半径 | m |
| R_clear | 成功清除距离阈值 | 20 m |
| R_near | 返回 near 的距离阈值 | 5 m |
| R_eff | 单源有效接收半径 | 1000–1500 m |
| R_arena | 比赛圆域半径 | 1800 m |
| R_pos_max | 正检测距离保守上界 | 1500 m |
| R_no_signal | 无信号必排除半径 | 1000 m；仅用于候选排序和矛盾诊断 |
| R_ring,Q3 | 问题 3 六点候选的环点半径 | 1150 m；尚待人工决定是否采用 |
| n_ring,Q3 | 问题 3 六点候选的等角环点数 | 6；另含中心点 |
| phi_ring,Q3 | 问题 3 六点候选首环点相位 | 10 degree |
| T_v | 虚拟总时间 | s |
| T_r | 真实运行时间 | s，最多 1200 |
