## 1. 比赛与感知约束（读图前先记住）

- **比赛区**：圆心原点，半径约 **1800 m**（图中虚线圆）。
- **机器狗速度**：5 m/s；虚拟时间主要由**走路 + 探测驻留**组成。
- **有效接收半径 `r_eff`**：约 **1000–1500 m**（最坏覆盖按 **1000 m** 设计）。
- **全向源**：听点在源的 `r_eff` 圆盘内即可听到。
- **定向源**：只在 **朝向 ±90° 的前半平面** 且距离 ≤ `r_eff` 时才能听到（图中扇形）。
- **清除**：须走到源附近 **≤20 m** 再 `/clear`（本 README 的图只画“搜索听点”，不画定位折返细线）。

---

## 2. 航路分层（对应图1）

策略把听点拆成四层，**按顺序执行**：

```
原点全扫(20信道)
  → 内圈巡游(8×1200)，去每个内圈点时若从原点出发则途中在 900m 停听
  → 外圈巡游(12×2100)，并启用“假定剩余源为定向”的剪枝
  → 仍 pending 的信道扫尾定位清除
```

### 2.1 原点 `(0,0)`

- 对信道 1–20 全部 `/measure`。
- 作用：抓住**靠近中心**的全向源，以及朝向原点的定向源。
- 听到后立刻进入定位清除（`drain`），再继续覆盖。

### 2.2 途中停听 `8 × 900 m`（青绿点）

- **不是**单独一圈任务环，而是：当机器狗从原点出发去某个 **1200 m 内圈点** 时，在**同一条射线上**的 900 m 处停一次。
- 专门对付 **近心、朝外** 的定向源：  
  源在 ~100–200 m、朝外时，1200 m 内圈点往往落在**后瓣**，听不到；900 m 停听点更容易落进前瓣。
- 单测 `test_near_center_outward` 依赖这一层；去掉会漏清。

### 2.3 内圈 `8 × 1200 m`（蓝点）

- 标准全向覆盖环：原点 + 8 点，覆盖证明用最小 `r_eff=1000 m`。
- 访问顺序：**最近邻 NN**（图中连线只是环上示意，不是真实 NN 折线）。
- 同环若落入已听点 **1000 m** 盘内会判冗余并跳过（**内圈不压制外圈**）。

### 2.4 外圈 `12 × 2100 m`（橙点）

- 落在比赛圆 **外侧**，用来保证：对场内任一位置、任一朝向，在其 **180° 前瓣 ∩ 1000 m 盘** 内至少有一个听点（定向前向覆盖条件）。
- 内圈结束后 `_inner_done=True`：外圈选点时假设“还能听的只剩定向”，用 `assume_directional` 剪掉已不可能的全向解释，少扫空信道。
- 12 点是当前与 `directional_front_cover_ok` 匹配的设置；内圈减到 6 点会挂覆盖证明。

---

## 3. 为什么外圈这么费时间

官方 10 局统计里，行驶约占虚拟时间 **84%**。  
外圈半径 2100 m、12 个点，空驶很长；全向偏多的局可以更早停搜（听清后 `heard≥16` 或无未知），均时更低（例如约 6.2k s）；定向偏重局外圈几乎跑满，可到 10k+ s。

## 4. 示例干扰源怎么读图

图例约定：

| 标记 | 含义 |
|------|------|
| 圆点（深蓝） | 全向干扰源 |
| 浅蓝圆盘 | 全向可听范围（示意 `r_eff=1000`） |
| 三角（红） | 定向干扰源 |
| 红色扇形 | 定向 180° 前瓣可听区 |
| 红箭头 | 定向朝向 |

### 图2 — 全向偏重

- 多数源可用 **原点 + 内圈** 听到（圆盘与蓝点重叠）。
- 外圈仍可能跑，但更容易因“已听够”提前结束。
- 对应官方里偏快的局（全向多、定向少）。

### 图3 — 朝外定向

- **近心朝外**（场心附近三角）：必须依赖 **900 m 途中停听**。
- **远区朝外**（外缘三角）：前瓣对着场外，常要 **2100 m 外圈** 听点落进扇形。
- 对应官方里偏慢、且 `clear_miss` 更高的局。

### 图4 — 混合对应关系

| 源类型 | 典型由谁听见 |
|--------|----------------|
| 场内全向 | 原点 / 内圈 |
| 近心朝外定向 | 900 m 途中停听 |
| 远区定向 | 外圈 2100 m |

定位阶段（紧凑二站 → Q4 不走远二站 → creep ≤8 → 扇形 12+18 m）发生在“听到之后”，不在这些覆盖图的折线上展开。

## 5. 策略参数速查（`v_nofar`）

| 项 | 值 |
|----|-----|
| 内圈 | 8 × 1200 m |
| 途中停听 | 去内圈射线上 900 m |
| 外圈 | 12 × 2100 m |
| 环内冗余 | 同环距离 ≤1000 m 跳过 |
| 第二站 | 紧凑正交 H=400, ρ=450 |
| Q4 远二站 | **跳过**（紧凑失败后直接 creep） |
| creep | 定向最多 8 步 |
| 扇形清除 | 12 m + 18 m |
| 停搜 | 已听+待清 ≥16（官方无 jammer_count 时） |
