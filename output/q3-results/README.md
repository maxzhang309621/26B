## 当前默认方案（`run_q3` / `run_q3_batch`）

骨架不变：**原点全扫 → 正六边形 6×1150（相位 10°）先搜后清 → RH 开放 TSP 批量清**。

在此之上保留的改动（`src/policy.py`）：

| 开关 / 函数 | 作用 |
|-------------|------|
| `Q3_COVER_EDGE_SECOND` + `_cover_edge_second_looks` | 环边 `start→dest` 上，对只听过 1 次、且**后续顶点补不上二测**的频道，在边上合法 Q2 候选带内补听 |
| `Q3_COVER_ENROUTE_EXTRA_M=280` + `_cover_enroute_clears` | 巡游中：≥2 示向后，若去清点相对下一听点 extra≤280 m，则顺路 `/clear` |
| `Q3_RH_DIRECT_MULTI_OBS` | 扫完后 RH：≥2 示向直奔服务点，不再切 280 m 步进听 |
| `_try_bearing_clears` | **只试最近 1 个**交点（避免远交点星形折返） |
| 光学网格收紧 | `MAX_CELLS=8`、`MAX_TRIES=1`、`MAX_SEC_R=28`、miss 即停；区大 / 近共线先补测，不瞎铺网 |

本地 mock（`q3_benchmark` 种子 0–39）：全清；边补二测打开后均约 **301.7 s/源**（关边补约 312.6）。

## 折返问题：试过什么、为什么回滚

时间大头在扫完后的 **clear_detour**（约 1.1–2.0 ks/局），不是 TSP 求解器本身。

扫完后盘点（边补二测前）：环上约清掉 1.3 个；剩 **~7.8 个只听 1 次**、**~3.9 个已听 ≥2 但还不能 20 m 清**。几乎没有「已经能清、只差更好访问顺序」的点。

| 改法 | 本地 40 种子均秒/源 | 结论 |
|------|---------------------:|------|
| 硬两波：先只排 ≥2 示向 | 354（+42） | 大交区中心当城市 → 乱飞 |
| 软偏置：近处 ≥2 才优先 | 319–326 | 净亏 |
| 未就绪不去 SEC、改去补测点 | 346 | 多跑一圈补测 |
| 扫完后再做宽松顺路清 | 314 | 几乎无益 / 略亏 |
| 只插入已 `can_clear_20` | ≈312.6 | 扫完后几乎触发不到 |

**结构结论：** 扫完后再拧访问顺序空间很小；要把折返砍下来，必须在**环上就把第二次示向做完**（边补二测），让扫完后的城市更像「真能清的点」，而不是「假想第二站 / 大 SEC 中心」。

边补二测后：环上剩 1 次示向约 **3.2**，≥2 次约 **7.0**，环上已清约 **2.8**；定位行驶从 ~475→~222 s。

## 对 Q4 能不能用

Q4 默认口径仍是 **`v_nofar` / 证书航路**，不要为了 Q3 实验改坏默认提交。

| Q3 技巧 | Q4 可迁移性 |
|---------|-------------|
| 环边补二测 | **部分可用。** Q4 有内环/外环与方向瓣；可对「只听 1 次且未来航点进不了候选带」的频道在**当前边**上插入二测。但外环跳点、方向源静默规则不同，不能原样拷贝 `in_candidate_region` 门控。 |
| 巡游顺路清（extra≤280） | **谨慎。** Q4 `pathopt` 已有插入/顺路逻辑；`v_nofar` 中途大绕会破坏证书航路时间。建议只对 `can_clear_20` / 站内 20 m 内启用。 |
| ≥2 示向直奔服务点 | **可用。** 与方向无关的行程节省；注意方向源 SEC / 瓣后试清预算。 |
| 只试最近交点 | **可用。** 减少星形折返，Q3/Q4 通用。 |
| 收紧光学网格 | **Q3 专用色彩重。** Q4 更依赖示向与瓣几何；大网格在方向噪声下更易空跑。 |
| 扫完后硬两波 TSP | **两边都别用**（本地已证变慢）。 |

Q4 若要试边补二测：先在 mock 上相对 `output/baselines.md` 的 **8898.8 s / 669 s/源** 报 Δ，再考虑问题4演练；**不要动正式**。
