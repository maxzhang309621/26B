# 2026B 无线电干扰源定位与清除 — 本队解答摘要

## 问题1
- **算法**：各站示向度 ±1° 扇形 → 边界射线交点 → 凸包得定位多边形 → 顶点最大距离为直径。
- **结论**：以该直径为直径的圆**不一定**能覆盖定位区域（等边三角形反例；三站示例也可能不覆盖）。

## 问题2
- 第二点取较大交会角（约 60°–90°），基线约 300–900 m。
- 候选区：沿示向度走廊 × 两侧正交/斜交偏置，优先落在目标圆内。
